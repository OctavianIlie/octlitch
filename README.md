## Octlitch Linux

Octlitch is a Fedora-based Linux distribution built around KDE Plasma, that is heavily customized and bloat free. This distro is highly opinionated since ithas removed everything extra that's not needed. I believe that a OS should come as bare bones as it can and the user installs whatever he needs.

> **Status:** Early development / alpha
> Octlitch is not yet recommended for production systems.

## Goals

- Fedora base for stability, security and immutability
- KDE Plasma desktop
- Dark, minimal visual design
- Compact bottom panel
- Sharp window decorations
- Multiple Octlitch color themes and wallpapers
- LibreWolf included as the default browser
- Minimal preinstalled application set
- No built-in AI agents or services
- SELinux and Fedora security infrastructure retained

## Current state

The development ISO currently includes:

- Fedora 44 base
- KDE Plasma
- Octlitch branding
- Octlitch Plymouth boot splash
- Octlitch KDE splash
- Custom KWin decoration
- Custom Plasma themes
- LibreWolf
- Customized live environment and installer launcher

## Warning

Octlitch is currently experimental software.

Expect bugs, incomplete hardware support, and breaking changes between builds.

Do not rely on development builds for important data without backups.
